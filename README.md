# Student Performance Stats

Решение финальной задачи курса «Программирование на Python».  
✅ 24 из 24 тестов.

---

## Задача

Посчитать статистику успеваемости учеников:

- максимальный, средний и минимальный процент рейтинга
- топ‑3 учеников по рейтингу (при равных значениях сохраняется порядок ввода)
- вывод «Курс усваивается хорошо» или «Курс усваивается плохо»

---

## Входные данные

Первая строка:  
`N M Q cw sw hw tw`

- `N` — количество учеников (≥ 3)
- `M` — количество занятий (> 0)
- `Q` — максимальный рейтинг (> 0)
- `cw, sw, hw, tw` — коэффициенты (> 0)

Далее для каждого ученика:
- фамилия
- `M` строк с оценками `a,b,c,d` (оценки за одно занятие)

---

## Выходные данные

- `max_percent avg_percent min_percent` (через пробел)
- топ‑3 учеников: `Фамилия процент%`
- строка «Курс усваивается хорошо» или «Курс усваивается плохо»

---

## Обработка ошибок

Программа проверяет:

- `n >= 3`, `m > 0`, `q > 0`, все коэффициенты > 0
- рейтинг каждого ученика (`total`) не превышает `Q`

Если условие нарушено → выводится `Во введённых данных ошибка`

---

## Запуск

```bash
python solution.py
```

## Особенности решения

- **Сортировка с лямбдой**:  
  `students.sort(key=lambda x: x[1], reverse=True)`  
  Позволяет отсортировать учеников по убыванию рейтинга, сохраняя порядок ввода при равных значениях.

- **Без `exit()`**:  
  Вместо аварийного завершения используется флаг `error`. Это корректно дочитывает входные данные, даже если ошибка уже найдена.

- **Проверка `q <= 0`**:  
  Исключает деление на ноль при расчёте процентов.

- **Лаконичность**:  
  Код занимает около 40 строк (в авторском решении — почти 100).

## Технологии

- Сортировка с `lambda`
- Округление `round()`
- Работа с вводом через `split()` и `split(",")`
